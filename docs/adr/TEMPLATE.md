* **Decided by:** who accepted it
* **Affects:** systems, public APIs, file formats, milestones

Status words:

* **Proposed**: written down, not yet accepted.
* **Provisional**: accepted so work can proceed, and expected to be revisited. Say what evidence would
  trigger the revisit (a measurement, a second implementation, a milestone).
* **Settled**: accepted; reopen only under the rule at the bottom of DECISIONS.md.
